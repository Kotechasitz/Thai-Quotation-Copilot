## 2. โมเดล AI

### 2.1 Gemini API (provider `google`)

ที่มา: ai.google.dev/gemini-api/docs/pricing อ่านเมื่อ 2026-10-27

- **Free tier:** ฟรี แต่ **ข้อมูลที่ส่งอาจถูกนำไปปรับปรุงผลิตภัณฑ์ของ Google** (หน้า pricing ระบุว่า free tier ใช้ข้อมูลเพื่อปรับปรุงผลิตภัณฑ์ และ paid tier ไม่ใช้) จึงใช้กับข้อมูลสังเคราะห์เท่านั้น
- **โควตา free tier:** `gemini-3.6-flash` ได้ **20 คำขอต่อวันต่อโมเดล** (วัดเมื่อ 2026-10-27 จากข้อความ error ของ API ไม่ใช่จากหน้าเอกสาร) 1 ใบเสนอราคาใช้อย่างน้อย 2 คำขอ (แยกรายการ 1 ครั้ง + จับคู่ครั้งละไม่เกิน 10 รายการ) จึงทำได้ไม่กี่ใบต่อวัน
- **Paid tier** ราคาต่อ 1 ล้าน token (Standard, text):

| โมเดล | Input | Output |
| --- | --- | --- |
| `gemini-3.6-flash` | $0.75 ถึง 2026-12-31 แล้วเป็น $1.50 ตั้งแต่ 2027-01-01 | $3.75 ถึง 2026-12-31 แล้วเป็น $7.50 ตั้งแต่ 2027-01-01 (รวม thinking tokens) |
| `gemini-2.5-flash` | $0.30 | $2.50 |

### 2.2 Vercel AI Gateway (provider `gateway`)

- ต้อง **เติมเครดิต** ก่อนใช้โมเดลที่คิดเงิน
- มี **เครดิตฟรีรายเดือน** สำหรับ **เฉพาะบางโมเดล** (ไม่ใช่ทั้ง catalog) เอกสารของ Vercel **ไม่ระบุจำนวนเงิน** และโมเดลนอกรายการฟรีต้องซื้อเครดิต คำขอบน free tier ถูกจำกัดอัตราต่อโมเดลต่ำกว่า paid tier
- **การซื้อเครดิตทำให้ทีมย้ายไปอยู่ paid tier และเครดิตฟรีรายเดือนไม่มีผลอีกต่อไป** ("Once you purchase credits, your account transitions to the paid tier and the monthly free credit no longer applies")
- **Zero Data Retention (ZDR):** ต่อคำขอ (per-request) ใช้ได้บน Pro และ Enterprise **ไม่มีค่าใช้จ่ายเพิ่ม**; แบบทั้งทีม (team-wide) **$0.10 ต่อ 1,000 คำขอ**
- แหล่งที่มา (สามข้อด้านบน): https://vercel.com/docs/ai-gateway/pricing (หน้าระบุ last_updated 2026-09-08, อ่านเมื่อ 2026-10-27)
- ราคาต่อโมเดลเป็นไปตามราคา list ของผู้ให้บริการโมเดลนั้น ตัวอย่าง `anthropic/claude-haiku-5.5` ตามหน้า pricing ของ Anthropic (platform.claude.com/docs/en/about-claude/pricing อ่านเมื่อ 2026-10-27): input $0.10 และ output $0.50 ต่อ 1 ล้าน token สำหรับ prompt ไม่เกิน 100,000 token (เกินนั้นเป็น $0.50 / $2.50)
- ตั้งค่าให้ส่ง `disallowPromptTraining: true` เสมอ (gateway เลือกเฉพาะผู้ให้บริการที่ไม่เทรนด้วย prompt) ไม่ใช่ ZDR และคำขอจะล้มเหลวถ้าไม่มีผู้ให้บริการที่ตรงเงื่อนไข

## 3. ต้นทุนต่อใบเสนอราคา (ประมาณการ)

**ตัวเลขที่วัดจริง (มีชุดเดียว):** การรันจริง 1 ใบเสนอราคาเมื่อ 2026-10-27 ผ่าน provider `google` ใช้ **27,635 input tokens และ 3,394 output tokens** ที่มา: ตัวเลขจากผลลัพธ์บนหน้าจอ (console) ของการรัน `npm run quote` กับ `samples/inquiries/01.txt` ในวันนั้น ไม่ได้เก็บไว้ใน repository

ข้อควรระวัง:

- วัดมาจากการรันเพียงครั้งเดียว ไม่ใช่ค่าเฉลี่ย
- วัด **ก่อน** เปลี่ยนมาใช้ candidate 20 อันดับแรกต่อรายการ ตอนนี้ใช้ token น้อยลง ดังนั้นต้นทุนจริงควรต่ำกว่านี้ (ยังไม่ได้วัดใหม่)
- แต่ละโมเดลนับ token ต่างกัน ตัวเลขนี้ใช้เทียบข้ามโมเดลได้เพียงคร่าว ๆ

**สูตร:** `ต้นทุน (USD) = input_tokens × ราคา_input ÷ 1,000,000 + output_tokens × ราคา_output ÷ 1,000,000`

**ตัวอย่างคำนวณ (ประมาณการ ไม่ใช่ผลวัด)** ด้วย 27,635 / 3,394 tokens และราคา list ในหัวข้อ 2 (อ่านเมื่อ 2026-10-27):

| โมเดล | คำนวณ | ประมาณต่อใบ (USD) |
| --- | --- | --- |
| `gemini-3.6-flash` (ราคาถึง 2026-12-31) | 27,635 × 0.75 ÷ 1e6 + 3,394 × 3.75 ÷ 1e6 | ~$0.033 |
| `gemini-3.6-flash` (ราคาตั้งแต่ 2027-01-01) | 27,635 × 1.50 ÷ 1e6 + 3,394 × 7.50 ÷ 1e6 | ~$0.067 |
| `gemini-2.5-flash` | 27,635 × 0.30 ÷ 1e6 + 3,394 × 2.50 ÷ 1e6 | ~$0.017 |
| `anthropic/claude-haiku-5.5` (prompt ไม่เกิน 100,000 token) | 27,635 × 0.10 ÷ 1e6 + 3,394 × 0.50 ÷ 1e6 | ~$0.0045 |

แถว `claude-haiku-5.5` ใช้จำนวน token ของ Gemini มาคำนวณ แต่ภาษาไทยมักถูกนับเป็น token มากกว่าบน Claude ตัวเลขแถวนี้จึง **มองโลกในแง่ดีเกินจริง** (ต่ำกว่าความเป็นจริง)

ตัวเลขข้างต้นยังไม่รวมการ retry เมื่อโมเดลตอบผิด schema และไม่รวมค่า hosting

## 4. เปรียบเทียบความแม่นยำ (eval)

**รอผล:** ยังไม่มีตัวเลขความแม่นยำที่ใช้อ้างได้ เพราะโควตา free tier ของ Gemini หมดระหว่างรัน eval ครั้งแรก (ลองรัน 1 เคส ถูกยกเลิกเพราะโควตารายวัน ยังไม่มีผลของเคสใดเลยจาก 25 เคส) และยังไม่ได้รันกับโมเดลที่เสียเงิน

ตารางด้านล่างจะเติมหลังรัน `npm run eval:daily` (Gemini free tier สะสมเคสวันละส่วน) และรัน eval กับโมเดลที่เสียเงินผ่าน gateway (เช่น `npm run eval -- --provider gateway --model anthropic/claude-haiku-5.5`) ซึ่งต้องเติมเครดิตและตั้ง key เอง
